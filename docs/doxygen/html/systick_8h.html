◆ SysTick_us()

void SysTick_us ( uint32_t val)

Blocking delay in microseconds.

Parameters
valDelay in µs (max = 0xFFFFFF / SYSTICK_CYCLES_PER_US ≈ 1.68 s @ 10 MHz).

LOAD = (val × SYSTICK_CYCLES_PER_US) - 1 cycles. Uses processor clock (CLKSOURCE = 1), no interrupt (TICKINT = 0).
