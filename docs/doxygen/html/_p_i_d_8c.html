Detailed Description

PID controller.

Version
V1.0.0
Date
18-06-2026

Formula: output (MV) = (kp * error) + (ki * integral) + (kd * derivivative) MV = manipulated variable

error = e(t) = SP - PV Setpoint (SP) Process Variable (PV)
